# Puzzle Game

A simple puzzle game built with Go, HTML, CSS, and JavaScript.

## Features

- 3 puzzle levels
- Lives system
- Hint system
- Score system
- Web-based interface
- Go HTTP server

## How to Run

```bash
go run .

## Then open:
http://localhost:8080

## Or build the executable:
go build -o puzzle-game.exe

./puzzle-game.exe

## Controls
Enter name and click Start Game
Type your answer
Click Answer to submit
Click Hint to get a hint
